UNIT 01CALCULUS

Limits & Continuity

Limits describe the value approached by a function as the input approaches a point. Continuity connects limits with the actual function value.

Limit

The statement lim(x→a) f(x)=L means f(x) approaches L as x approaches a, even if f(a) is not defined or is different.

Continuity at x=a

A function is continuous at a if f(a) exists, lim(x→a)f(x) exists, and the limit equals f(a).

Important standard limit: lim(x→0) (sin x)/x = 1.
Example: For f(x)=x²+3, lim(x→2)f(x)=4+3=7 because polynomials are continuous everywhere.
UNIT 02CALCULUS

Differentiation & Applications

Differentiation measures the instantaneous rate of change and is used for slopes, approximation and optimization.

Basic rules

d(xⁿ)/dx = nxⁿ⁻¹
d(sin x)/dx = cos x
d(cos x)/dx = −sin x
d(eˣ)/dx = eˣ
d(ln x)/dx = 1/x

Product and quotient rules

For y=uv, y′=u′v+uv′. For y=u/v, y′=(vu′−uv′)/v².

Maxima and minima

Find critical points by solving f′(x)=0 or identifying points where f′ is undefined. Then use a sign test or second derivative test to classify the stationary point.

Example: If f(x)=x²−4x+3, then f′(x)=2x−4. The stationary point occurs at x=2; f′′(x)=2>0, so it is a local minimum.
UNIT 03CALCULUS

Integral Calculus

Integration is the reverse process of differentiation and is used for area, accumulation and many engineering quantities.

Basic integrals

∫xⁿ dx = xⁿ⁺¹/(n+1)+C, n≠−1
∫1/x dx = ln|x|+C
∫cos x dx = sin x+C
∫sin x dx = −cos x+C

Integration by parts

When an integrand is a product of functions, use ∫u dv = uv − ∫v du. Choosing u appropriately can simplify the remaining integral.

Definite integrals

For a continuous function, ∫ₐᵇ f(x)dx represents signed area between the curve and the x-axis from a to b. Areas below the axis contribute negatively.

UNIT 04LINEAR ALGEBRA

Matrices & Determinants

Matrices provide a compact way to represent linear equations and transformations.

Matrix operations

Matrices of compatible dimensions can be added, subtracted and multiplied. Matrix multiplication is generally not commutative: AB may differ from BA.

Determinant of a 2×2 matrix

For A = [[a,b],[c,d]], det(A)=ad−bc.

Inverse

A square matrix has an inverse only when its determinant is non-zero. For a 2×2 matrix, A⁻¹=(1/det A)[[d,−b],[−c,a]].

Exam tip: Show row/column operations clearly and keep matrix dimensions visible during multiplication.
UNIT 05LINEAR ALGEBRA

Systems of Linear Equations

A system of linear equations can be solved using elimination, matrix methods or determinants.

Gaussian elimination

Convert the augmented matrix into an upper-triangular or row-echelon form using elementary row operations, then use back-substitution.

Consistency

A system is inconsistent when the equations lead to a contradiction such as 0=non-zero. A consistent system can have a unique solution or infinitely many solutions depending on the rank and number of unknowns.

Example: For x+y=5 and x−y=1, adding the equations gives 2x=6, so x=3 and y=2.
