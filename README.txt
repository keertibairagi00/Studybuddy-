# StudyBuddy

A student-friendly exam-ready notes website.

## Files
- index.html — website structure/content
- style.css — colors, layout, responsive design
- script.js — search, note popups and subject interactions

## How to add a new note
Open `index.html` and copy one of the `<article class="note-card">` blocks.
Change its title, subject and description.

Then open `script.js` and add a new entry inside `const notes = { ... }`.

## Publishing
This is a static website, so it can be published on GitHub Pages, Netlify, Vercel, or another static hosting service.
